# Разработка Kitai

Координатор проекта — GPT-6.2 Astra с уровнем max. Если max недоступен, используй xhigh или самый высокий поддерживаемый уровень. Для ручного выбора модели проверь настройки текущего сеанса. Используй авторизацию ChatGPT. Подключение платных API требует отдельного разрешения.

Роли и границы редактирования заданы в .codex/agents. Запускай до четырёх субагентов по мере необходимости. Независимые задачи выполняй параллельно. Координатор назначает владельца каждого файла, проверяет результаты и интегрирует изменения.

Сначала проверь официальные API Taobao, 1688 и Alibaba.com, затем зафиксируй архитектуру, техническое задание и план реализации. Android, backend и интеграции разрабатывай параллельно при согласованных контрактах. После реализации перевода и интерфейса проверь реальные скриншоты эмулятора с Terra high, если эмулятор доступен.

Передавай Astra проблемы архитектуры, безопасности, потери данных, интеграций, сложного Gradle, многопоточности и производительности. Также эскалируй дефект после двух обоснованных попыток исправления. Типовые исправления поручай Sol high.

Перед релизом выполни независимые проверки кода и безопасности, исправь P0/P1 и повторно проверь критические компоненты. Проверь реальные интеграции, русификацию, перевод, производительность, APK, CI и инструкции эксплуатации. Публикуй релиз после прохождения проверок. Документацию веди на русском.
