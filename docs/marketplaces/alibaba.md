# Alibaba.com

**Проверено 24 ноября 2026 года.** У Alibaba.com есть официальный покупательский API поиска товаров по ключевым словам и отдельный метод подробностей. Они входят в программу Buyer Sourcing Solution. Программа рассчитана на закупщиков и партнёров, которые подключают поиск к своей системе. Для Kitai подтверждены опубликованные контракты. Доступ приложения к действующей выдаче пока не проверен. [Buyer Sourcing Solution](https://openapi.alibaba.com/doc/doc.htm#/?docId=96) · [Справочник Product Search](https://openapi.alibaba.com/doc/api.htm#/api?cid=7&path=/eco/buyer/product/search&methodType=GET)

## Поиск и карточка

| Метод | Запрос | Ответ |
| --- | --- | --- |
| `GET /eco/buyer/product/search` | `param0` содержит обязательные `keyword`, `index` с 1 и `size` до 50. Дополнительные параметры включают `currency` по ISO 4217, `language`, `shipFrom`, `shipToCountry` и `productType`. | `result.data.products` содержит `product_id`, `title`, `price`, `permalink`, основное и дополнительные изображения. Сведения о страницах находятся в `result.data.pagination`. |
| `GET /eco/buyer/product/description` | `query_req` содержит обязательный `product_id`. Можно указать `language` по BCP 47, `currency`, `country` и `ship_to_country`. | `result.result_data` содержит поставщика, описание, фотографии, минимальную партию, состояние товара и ценовые ступени по SKU. Каждая ступень указывает количество, цену и валюту. Флаг `is_inquiry` показывает, когда требуется уточнение у продавца. |

В поиске цену возвращает строка без отдельного поля валюты, поэтому при запросе для сравнения стоит явно передавать валюту, например `USD`. В карточке следует использовать валюту из ответа и цену для выбранного количества. Публичная схема поиска не содержит рейтинг или число отзывов поставщика. Эти значения сохраняют неопределёнными, пока их не предоставит разрешённый источник. [Параметры поиска](https://openapi.alibaba.com/doc/api.htm#/api?cid=7&path=/eco/buyer/product/search&methodType=GET) · [Параметры карточки](https://openapi.alibaba.com/doc/api.htm#/api?cid=7&path=/eco/buyer/product/description&methodType=GET)

## Ключи, цена и ограничения

Владелец регистрирует разработчика и приложение подходящей категории, получает одобрение, `App Key`, `App Secret` и права для покупательских методов. Buyer Sourcing Solution предусматривает активную учётную запись покупателя. В примере запроса присутствует `access_token`. Сервер подписывает параметры HMAC-SHA256 с секретом приложения и обращается к `https://openapi-api.alibaba.com/rest`. [Начало работы](https://openapi.alibaba.com/doc/doc.htm#/?docId=19) · [Разрешения приложения](https://openapi.alibaba.com/doc/doc.htm#/?docId=54) · [Подпись](https://openapi.alibaba.com/doc/doc.htm#/?docId=60) · [Адрес шлюза](https://openapi.alibaba.com/doc/doc.htm#/?docId=61)

Общее соглашение различает платные и бесплатные API. На проверенных страницах покупательских методов отсутствуют единая цена поиска и гарантированное число запросов в секунду или в сутки. Их необходимо подтвердить для конкретного приложения. Ограничение в 50 товаров относится к размеру одной страницы. Ручной поиск по товару или поставщику доступен на Alibaba.com. Покупатель также может запросить индивидуальную цену через RFQ. [Условия API, раздел 8](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_b2b/suit_bu1_b2b201911081026_96467.html) · [Инструкция для покупателей](https://buyer.alibaba.com/page/how_it_wroks.html)

## Практическая проверка

Схемы обеих операций и примеры ответов изучены в открытой документации. Запроса с ключами Kitai не было. После одобрения приложения нужно найти `stainless steel thermos` с явно выбранной валютой, проверить вторую страницу и открыть подробности по одному полученному `product_id`. В журнале проверки достаточно сохранить время, идентификатор запроса и коды результата. В примерах успешного ответа внешний `code` равен строке `0`, а внутренний код равен строке `200`. Подлинность товара, актуальную цену, доставку и условия поставки подтверждают по текущему предложению поставщика.
