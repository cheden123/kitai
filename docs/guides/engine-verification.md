# Проверка локального перевода и OCR

Проверено 24 ноября 2026 года через API Kitai в Ubuntu 22.04 на WSL. Использованы LibreTranslate 1.9.6 с локальными моделями, Tesseract 4.1.1 и шесть синтетических изображений. В каталог подавались тестовые предложения. Площадкам запросы не отправлялись.

| Направление | Пример результата | Первый / повторный запрос |
| --- | --- | --- |
| RU → ZH | Настольная лампа с тёплым светом → 暖光台灯 | 2,68 с / 4 мс |
| ZH → RU | 无线蓝牙耳机，支持主动降噪 → Беспроводная Bluetooth-гарнитура, поддержка активного шумоподавления | 5,96 с / 3 мс |
| EN → RU | A stainless steel bottle with a capacity of 750 ml → Бутылка из нержавеющей стали емкостью 750 мл | 0,21 с / 2 мс |

Поиск отправил китайский перевод русского запроса тестовому адаптеру. Для китайской и английской тестовых карточек backend добавил русский заголовок. Замеры относятся к одному локальному прогону. Лимит фонового вызова перевода из каталога увеличен с 2 до 8 секунд, чтобы дать движку время на первый запрос.

Tesseract вернул HTTP 200 для шести изображений. Три образца с русским или английским текстом распознаны дословно. Пустое изображение не вернуло блоков. Китайский стандартный пакет ошибся на обоих образцах. Пакет tessdata_best исправил однострочный образец, но на двухстрочном остались ошибки. Подмена иероглифов приводила к смысловой ошибке в переводе, поэтому китайские результаты требуют сверки с оригиналом.

После прерывания первой загрузки моделей LibreTranslate может стартовать с неполными направлениями. Восстановление через принудительное обновление моделей проверено. [Развёртывание и восстановление](synology.md)
